Got a recipe on paper, in a cookbook, or saved as a screenshot? Expo can read it from an image so you don't have to type it out.

## Import from a photo

1. Start an import in Expo and choose to import from photos.
2. Take a photo of the recipe — a cookbook page, a handwritten card, or a magazine clipping — or pick existing images from your library.
3. Expo reads the text in the image and builds the recipe.
4. Review the ingredients and steps, fix anything that didn't read cleanly, and save.

## Tips for the best results

- Use good lighting and lay the page flat so the text is sharp.
- Capture the whole recipe, including the ingredient list and all the steps.
- If a recipe spans more than one page, include each page so nothing is cut off.

## Screenshots work too

If you've saved a recipe as a screenshot, import it the same way you would any photo. Expo reads the text out of the image and turns it into a structured recipe.

If part of the recipe doesn't come through, edit it after importing, or email support@heyexpo.com.
